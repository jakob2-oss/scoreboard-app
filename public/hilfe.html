Oina no?, der Punktezettel für Spieleabende

Eine Partie starten

Auf der Startseite ein Spiel antippen, Spieler wählen, los. Spielende, Leben oder Deckel stellst du auf der Seite des Spiels ein.

Eigenes Spiel

Unter Eigene Spiele auf Eigenes Spiel erstellen tippen. Die Regelkarte oben zeigt sofort, was deine Einstellungen bedeuten.

Daten auf ein neues Gerät bringen

Im Reiter Spieler unter Daten eine Sicherung speichern und auf dem neuen Gerät mit Sicherung einlesen übernehmen. Das gilt auch für den Umzug von der Version im Browser in die App.

Etwas klappt nicht?

In der App ganz unten auf der Startseite Feedback geben, oder ein Ticket auf der Projektseite auf GitHub anlegen.
